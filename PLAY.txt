StarChem v1.8.1 quick start

Requirements
- Java 17 or newer.
- Extract the COMPLETE StarChem release ZIP before launching.
- Keep StarChem.jar, config/, the launchers, and the packaged documentation together.

Windows player
1. Open the extracted StarChem folder.
2. Run run-starchem.bat.
3. Use SOLO for a local game or JOIN for multiplayer.

Linux player
1. Open a terminal in the extracted StarChem folder.
2. Run:

   ./run-starchem.sh

Dedicated server
Windows:

   run-starchem-server.bat

Linux:

   ./run-starchem-server.sh

Both dedicated-server launchers default to TCP port 50000 and server name StarChem-Server. Run this for the complete supported command-line option list:

   java -jar StarChem.jar --help

Direct player launch, if needed:

   java -jar StarChem.jar

Direct dedicated-server launch, if needed:

   java -Djava.awt.headless=true -jar StarChem.jar --server 50000 --name StarChem-Server

Do NOT run:

   java StarChem.jar

The -jar flag is required for a direct Java launch.

StarChem v1.8.1 multiplayer uses protocol 17 and rules version 27. Dedicated-server save format 6 is current.

Important multiplayer update rule: v1.8.0 and v1.8.1 do not connect to each other because the compatibility handshake also requires an exact matching application version. Update the server and all clients together.

Existing v1.8.0 save-format-6 server data does not require a new save migration for v1.8.1. Back up the complete server-data directory before updating anyway.
