# Compact production menus

All station production interfaces use the shared native Swing production popup.

- Every row includes a visual preview for the represented ship, station, material, research topic, category, or queue action.
- Required resource costs are intentionally omitted from the normal list and shown when the row is hovered.
- Normal rows are 68 pixels tall and compact navigation or queue-action rows are 44 pixels tall so more choices fit onscreen.
- The vertical scrollbar remains visible and supports wheel, trackpad, scrollbar-drag, Page Up, and Page Down input.
- Research-gated ships, station packages, and manufacturing recipes stay hidden until unlocked, including while free-build mode is enabled.
