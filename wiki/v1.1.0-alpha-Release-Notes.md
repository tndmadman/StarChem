# v1.1.0-alpha Release Notes

Release tag: `v1.1.0-alpha`  
Tagged commit: `81075c4618bed69dca7a0e53f6d8ca4628683384`  
Rules version: 14  
NPC AI version: 5

StarChem v1.1.0-alpha is a major alpha update centered on multi-system galaxy simulation, territory control, a deeper manufacturing economy, autonomous NPC factions, framed TCP multiplayer, and production Linux server support.

## Highlights

- Persistent galaxy with 14 configured static system templates.
- One or two permanent copies of each template per session.
- Deterministic wandering-wormhole shortcuts.
- System roles, tags, resource identities, and environmental modifiers.
- Capturable command zones with controller bonuses.
- 24 raw resources, 56 manufactured intermediates, three salvage resources, and 60 recipes.
- Four-stage research progression from industry to supercapitals.
- Specialist mining, logistics, combat, capital, and megastructure hulls.
- Full Corsair economy, research, fleets, and cross-system expansion.
- Framed TCP networking with bounded queues, compatibility fingerprints, reconnect recovery, and slow-client isolation.
- Headless Linux dedicated server with packaged launch script and process-level CI smoke test.

## Galaxy and systems

The release expands the game from a single-sector prototype into a persistent connected galaxy.

Configured templates:

1. Sol Standard
2. Red Dwarf Foundry
3. Gas Giant Frontier
4. Ice Belt
5. Warzone
6. Corsair Den
7. Empty Frontier
8. Binary Forge
9. Volcanic Crucible
10. Nebula Expanse
11. Shattered Worlds
12. Pulsar Reach
13. Carbon Basin
14. Ancient Graveyard

Each template defines its own dimensions, role, tags, celestial layout, belt geometry, resource composition, and environmental modifiers.

The galaxy supports one or two copies of each template. Permanent topology remains connected, while the host can add 0–32 deterministic wandering-wormhole pairs. The default is four pairs.

Inactive systems continue progressing through tiered background scheduling. Dynamic and abandoned systems can be pruned with deletion notices propagated to connected clients.

## Territory control

Shared static systems contain a central command zone.

- Minimum eligible influence: 3.
- Uncontested capture time: 75 seconds.
- Station influence: 4.
- Armed-ship influence: 1.5.
- Unarmed non-miner influence: 0.75.
- Harvest-capable ship influence: 0.5.
- Multiple eligible factions create a contested state.
- Empty command zones cause capture decay.
- Player-home systems are protected.

Controller bonuses:

- 12% mining yield.
- 8% shield regeneration.

The galaxy map shows controller rings, control state, and capture progress.

Materials now carry JSON-defined display metadata, family, tier, color, and raw/manufactured status.

The release includes:

- Ten raw metals.

- Fuel.
- Scrap Metal, Hull Plating, and Circuit Fragments.
- Alloys and composites.
- Chemicals and coolants.
- Electronics.
- Industrial assemblies.
- Power and defense systems.
- Weapon assemblies.

Manufacturing recipes are split across category files and loaded through the top-level manifest. Recipes can require completed research.

The first Manufacturing Plant, starter Prospector, and Deployer remain directly buildable from raw resources. Salvage can be reclaimed into structural and electronic components.

## NPC simulation

Three enabled factions ship in NPC AI version 5:

- Raiders: reactive combat attackers.
- Free Miners: non-hostile resource workers.
- Corsair Syndicate: autonomous faction with workers, industry, research, stations, support ships, combat fleets, raids, harassment, retreat logic, and cross-system footholds.

NPC state is isolated per system. The organized faction can manufacture the complete recipe catalog and recursively satisfy missing subcomponents.

## Multiplayer rewrite

Multiplayer now uses framed TCP rather than UDP.

Transport features:

- One full-duplex connection per client.
- Four-byte big-endian length framing.
- Strict UTF-8.
- Maximum payload size of 512,000 bytes.
- Maximum 128 simultaneous connections.
- Dedicated reader and writer threads.
- Bounded inbound and outbound queues.
- Explicit delivery classes.
- Replaceable snapshot slots and ordered control traffic.
- Slow-client isolation.

Compatibility is checked before player state is created:

- Protocol version.
- Application version.
- Build commit.
- Rules version.
- Configuration fingerprint.

Session recovery retains identity, assets, research, production, home, and view state during the reconnect grace period. Resume tokens rotate after recovery.

Remote system views use request revisions to reject stale A → B → A responses.

## Linux dedicated server

The release ZIP includes:

```text
run-starchem-server.sh
```

Default command behavior:

- TCP port 50000.
- Server name `StarChem-Server`.
- Fixed 60 Hz simulation.
- Bounded catch-up.
- Status output every 60 seconds.
- Clean `Ctrl+C` and `SIGTERM` shutdown.

The release workflow smoke-tests the packaged JAR as a real headless Linux process, waits for TCP readiness, sends `SIGTERM`, and verifies a clean exit.

## Validation and hardening

Verification covers galaxy topology, system lifecycle, territory control, material coverage, recipe dependencies, progression gates, modifiers, NPC isolation and expansion, background scheduling, compatibility, TCP fault handling, session recovery, view switching, celestial continuity, Linux server lifecycle, legal notices, and package layout.

Release builds derive version identity from the tag, embed the commit, run the full verification suite, and publish a compiled ZIP.

## Compatibility

- Java 17 or newer is required.
- v0.1.5 clients cannot connect to v1.1.0-alpha servers.
- Every multiplayer participant must use matching build and configuration files.
- The release uses TCP, not UDP.

## Known issue discovered during documentation audit

### Research bootstrap blocker

The tagged configuration contains a circular dependency:

- Advanced Industry must be researched at a Research Lab.
- The Research Lab costs Radiation Shielding.
- Radiation Shielding requires Advanced Industry.
- A new player begins with neither completed research nor Radiation Shielding.

This blocks the normal research progression in a clean non-developer session. The configured tree and later hulls remain documented, but normal access requires a future fix or a deliberate nonstandard/developer workaround.

## Not included in this release

Current `main` contains later work that is not part of the tag, including server-side auto-production planning and configurable text-to-speech narration. Those features are excluded from this wiki’s release behavior and should not be advertised as available in v1.1.0-alpha.
